# Agent-owned output and Auto-fix Merge Requests

Agents directly submit GitLab Notes and do not need to return a canonical JSON result. Each Note carries a stable `ReviewFlow-Run-ID:<run-id> SHA:<sha>` marker and is checked before a retry by the configured Review Bot author. If auto-fix is enabled, the Worker persists an intent before Agent execution; the Agent creates an independent MR targeting the original source branch for the original MR creator to review and includes a Run/SHA intent marker in its description. User-controlled titles or branches cannot establish Auto-fix identity without that intent/relation and marker.
